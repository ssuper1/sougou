# 搜狗符号 v0.86

用于搜狗输入法 26 键符号自定义的 LSPosed 模块。需要 Android 7.0+、Root 和可用的 LSPosed/Xposed 环境，作用域仅勾选搜狗输入法。

## 本次发布

- 适配搜狗 12.0 与 20.17.0，中文、英文可分别配置字母和独立标点键。
- 修复「仅上划」时长按气泡出现 NO GLYPH 的问题，气泡显示及长按输出保留原符号。
- 搜狗 v20 的独立逗号、句号键显示并点击输出自定义符号，三种模式均生效；v12 仅替换点击输出。
- 修复符号面板点选被按键映射误替换的问题。
- 优化常规提交快路径、气泡反射及文本缓存、类加载发现与热补丁监听，减少重复工作和日志。
- 避免重复并发重启，在键盘显示、失焦和页面退出时取消唤起重试，清理 Root 子进程资源。
- 支持横屏、大键设置、深色模式及 Android 15+ 系统栏适配。

## 安装与升级

安装 `SogouSym-v0.86.apk`，在 LSPosed 启用模块并勾选搜狗作用域。配置后点击「重启搜狗生效」；升级 APK 后也需强行停止搜狗再打开，才能加载新 Hook。

版本：`0.86`，versionCode：`96`，包名：`com.qoder.sogousym`。本次为启用代码优化的 Release 包，沿用当前开发签名；自行构建使用的其他密钥可能无法覆盖安装。附件 `SHA256SUMS.txt` 可用于核对 APK 完整性。

## 验证与限制

- 18 项单元测试通过，Release 构建通过；Release lint 为 0 错误、22 条警告。
- v20 实机验证三种模式、中英独立标点键显示与提交、S 长按、符号面板及生命周期/重启行为。
- Release 包验证 `✘/✔/★/♡` 和 `8/9/x/y` 的显示与点击输出。
- v12 气泡修复曾实机验证，用户手动上划 S 输出 `✘`；后续热补丁监听解除条件调整仅做单元测试和反汇编检查，尚未重新安装 v12 回归。
- 自动合成手势不能可靠覆盖搜狗的实际上划识别；其他搜狗版本、皮肤和布局不保证兼容。
- 已完成短时持续输入与闲置恢复测试，未做长期耗电测量或所有 ROM 的稳定性验证。

ColorOS 重装搜狗后的卡死曾定位为系统 HANS 的旧输入法 UID 缓存。切到另一款输入法再切回可刷新记录；这属于系统侧排查结果，本 APK 不包含修改系统冻结策略的功能。更多说明见仓库 README。
